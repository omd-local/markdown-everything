Full Power Demo

Run OMD on your own machine when a conversion needs local files, browser cookies, Douyin/XHS authentication, local output folders, or local Ollama.

Run Locally

pip install -e '.[ui]'
omd-ui

The browser UI opens on http://127.0.0.1:7860. Sensitive inputs stay on your computer and are used only by the local OMD process.

Use This For

  • typed local file paths and local output folders
  • Douyin/XHS cookies and browser cookie extraction
  • local Ollama polish
  • longer media jobs bounded by your own machine

Hosted Sample Demo Boundary

The hosted sample demo intentionally blocks cookies, browser-cookie extraction, local paths, Ollama, kept media files, and Douyin/XHS authenticated conversion.
