Hosted sample template

Safe public mode accepts public URLs plus document/image uploads, then returns a Markdown preview and download. Media transcription is disabled by default. It does not read browser cookies, local paths, or local Ollama. The repository intentionally does not embed a Space owned by a maintainer's personal account.

Deploy the template under an organisation account and do not upload sensitive, private, or regulated files to a public Space.

Full Power Demo

Install OMD locally and run omd-ui. The UI opens on 127.0.0.1, so sensitive features stay on your machine.
